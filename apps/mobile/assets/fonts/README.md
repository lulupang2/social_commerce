# SummerGear 모바일 폰트

이 폴더에는 앱 번들에 포함되는 정적 폰트 파일만 보관합니다. Variable Font 대신 실제 사용하는
굵기만 포함해 Expo Go, native build, web에서 동일한 typography 이름을 사용합니다.

| 패밀리           | 출처                                                            | 포함 굵기               | 라이선스                  |
| ---------------- | --------------------------------------------------------------- | ----------------------- | ------------------------- |
| Pretendard 1.3.9 | <https://github.com/orioncactus/pretendard>                     | Regular, SemiBold, Bold | `OFL-Pretendard.txt`      |
| Paperlogy 1.001  | <https://github.com/Freesentation/paperlogy>                    | 7Bold, 8ExtraBold       | `OFL-Paperlogy.txt`       |
| Barlow Condensed | <https://github.com/google/fonts/tree/main/ofl/barlowcondensed> | Bold                    | `OFL-BarlowCondensed.txt` |

역할은 다음과 같이 고정합니다.

- Pretendard: 본문, 상품명, 버튼, 탭, 채팅 등 기본 UI
- Paperlogy: 화면 제목과 hero headline
- Barlow Condensed: 영문 eyebrow, 가격 숫자, 통계 숫자

폰트 파일을 교체할 때는 공식 배포본을 사용하고 같은 변경에서 라이선스와 이 문서를 갱신합니다.
