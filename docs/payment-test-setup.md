# 토스페이먼츠 테스트 연동 준비

상태: 테스트 PG 선정, 구현 전 · 기준일: 2026-09-18

DB는 Supabase PostgreSQL, 인증·API는 Go + Fiber, 작업 큐는 River입니다. 테스트 앱과 worker는 nhn-rocky에서 실행합니다. PG는 토스페이먼츠 테스트 환경이며 실제 결제·판매자 지급은 포함하지 않습니다.

## 사용자가 준비할 것

| 항목          | 준비할 내용                                                                                |
| ------------- | ------------------------------------------------------------------------------------------ |
| Supabase      | 기존 프로젝트에 실제 데이터가 있는지 확인, 테스트 전용 프로젝트 또는 격리 환경 확보        |
| DB 연결       | 테스트 프로젝트 Connect 화면의 direct 또는 session pooler 연결 정보, 서버 비밀 설정에 저장 |
| 토스페이먼츠  | 개발자센터 계정과 테스트용 client key·secret key, 선택한 SDK와 맞는 키 종류                |
| 네이버·카카오 | 개발자 앱 등록, client ID·secret 준비, 전달받은 콜백 URL 등록                              |
| 서버          | nhn-rocky 원격 저장소 경로와 사용할 테스트 도메인 확인                                     |
| 도메인        | 테스트 도메인의 DNS를 서버로 연결; HTTPS·프록시 설정은 구현 작업에 포함                    |

토스페이먼츠 신청 전에는 개발 연동 체험 상점의 일부 테스트 키를 확인할 수 있습니다. 키별 사용 가능한 연동 방식·결제수단이 다르므로 선택한 결제 SDK와 테스트 키의 종류를 맞춥니다. 임의의 키 조합이나 모든 간편결제 지원을 가정하지 않습니다. [API 키 공식 안내](https://docs.tosspayments.com/reference/using-api/api-keys)

키와 DB 비밀번호는 채팅·Git에 붙이지 않고 서버의 접근 제한된 환경 파일 또는 비밀 설정에 저장합니다. 구현자가 제공한 빈 환경 템플릿에 입력하고 파일 경로·준비 여부만 알려줍니다. client key는 프런트용 공개 설정으로 쓸 수 있지만 secret key는 서버 전용입니다.

## 구현 범위

1. Go API·River worker와 Supabase 연결·권한·migration·health를 구성합니다.
2. 네이버·카카오 인증, 회원·서비스 세션과 기존 사용자 연결을 구현합니다.
3. 테스트 판매자·상품으로 주문을 생성하고 가격·통화·소유권을 서버에서 검증합니다.
4. 토스페이먼츠 테스트 결제 요청·승인·조회·취소와 웹훅을 구현합니다. 구체적인 위젯/결제창 SDK는 확보한 키와 현재 공식 가이드에 맞춰 확정합니다.
5. River로 미결제 예약 만료·결제 결과 대조를 처리합니다.
6. nhn-rocky의 테스트 앱에서 성공·실패·중복·금액 변조·worker 재시작·PG 응답 유실을 확인합니다.

PG 연습만으로 입점사 지급대행이 완성되지는 않습니다. 실서비스 계약·에스크로·판매자 심사·정산 및 지급은 후속 범위입니다. 토스페이 간편결제 자체도 필요하면 선택한 테스트 키의 지원 여부를 별도로 확인합니다.

## 구현 요청에 포함할 정보

- 원격 프로젝트 경로, 테스트 도메인, 비밀 설정 파일 경로
- Supabase 실제 데이터 존재 여부, 테스트 프로젝트 구분
- 소셜 앱과 PG 테스트 키 준비 여부
- 목표: 실제 토스페이먼츠 테스트 환경까지 검증한 배포
- 완료 증거: 커밋·테스트 명령·환경·결과, 접속 주소와 남은 미검증 항목

자격 증명이 아직 없어도 서버 기반·migration·가짜 PG를 이용한 단위·통합 테스트는 진행할 수 있습니다. 실제 제공자 연동은 자격 증명 준비 후 수행하고, 가짜 응답 테스트를 실제 PG 검증으로 표시하지 않습니다. 서버에 최신 문서가 없으면 로컬 변경을 보존하여 전달하는 단계부터 진행합니다.

서버 작업 환경의 실제 파일 위치는 [nhn-rocky 준비 안내](../ops/nhn-rocky/README.md)를 참고합니다. 공개 저장소를 HTTPS로 내려받으며 서버에 GitHub 인증 토큰이나 배포 키를 보관하지 않습니다.
