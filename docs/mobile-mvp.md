# IceGear 모바일 MVP 콘텐츠 가이드

이 문서는 2026-08-14 기준 모바일 화면의 한국어 문구와 데모 콘텐츠 규격을 정의합니다. 제품·권한 경계는
`docs/SSOT.md`를 따르며, 이 문서는 route 로직이나 공개 정책을 새로 정의하지 않습니다.

## 문구 원칙

- 기본 말투는 간결한 해요체로 통일하고, 버튼은 `찾기`, `임시저장`, `다시 시도`처럼 행동을 먼저 씁니다.
- 사용자가 만든 판매글과 커뮤니티 글은 먼저 `임시저장` 또는 `초안`으로 안내합니다. 일반 작성자에게
  `게시 완료`나 `공개 완료`라고 알리지 않습니다.
- 규칙 기반 결과는 `맞춤 추천`, 근거는 `추천 이유`라고 부릅니다. 실제 모델 호출이 없는 결과에
  `AI 추천`, `AI 분석`, `AI가 골랐어요` 같은 표현을 쓰지 않습니다.
- 장비의 안전성, 정품 여부, 거래 성공, 인기 순위처럼 데이터로 확인할 수 없는 내용을 보장하지 않습니다.
- 감사 가능한 완료 기록이 없는 거래·재사용 수치는 숨깁니다. 데모 상품, `active`/`sold` 상태를 성과로
  집계하거나 CO2/CO₂·탄소 절감량으로 환산하지 않습니다.
- 오류는 원인 추측보다 현재 상태와 다음 행동을 알려줍니다. Production 오류를 데모 데이터로 조용히
  대체하지 않습니다.

## 타이포그래피 사용표

한글 본문과 조작 요소에는 Pretendard를 사용합니다. Paperlogy는 짧은 제목에만, Barlow Condensed는 영문이나
숫자에만 사용해 한글 대체 글꼴이 섞이지 않게 합니다.

| 역할 | 폰트 상수 | 크기/행간 기준 | 사용 예 | 사용하지 않는 곳 |
| --- | --- | --- | --- | --- |
| 화면 대표 제목 | `displayExtraBold` | 28/36 | 홈 hero, 인증 첫 제목 | 긴 설명, 오류 본문 |
| 섹션 제목 | `displayBold` | 22/30 | `맞춤 추천`, `겨울 스포츠 이야기` | 버튼, 입력 label |
| 카드 제목 | `bodyBold` | 17/24 | 상품명, 커뮤니티 글 제목 | 가격 숫자 |
| 기본 본문 | `body` | 15/23 | 상품 설명, 도움말, 빈 상태 설명 | 한 줄 badge |
| 보조 본문 | `body` | 13/19 | 지역·시간, 입력 도움말, 상태 설명 | 핵심 오류 제목 |
| 버튼·입력 label | `bodySemiBold` 또는 `bodyBold` | 15/20 | `검토 요청`, `다시 시도` | 긴 문장 |
| 상태 badge | `bodySemiBold` | 12/16 | `초안`, `검토 대기`, `데모 데이터` | 본문을 대신하는 상태 설명 |
| 가격·통계 숫자 | `accentBold` | 24/28 | 가격의 `480,000` 숫자, 근거가 있는 count | `원` 같은 한글 통화명, 추정 지표 |
| 영문 eyebrow | `accentBold` | 13/16 | `ICEGEAR`, `SKI`, `HOCKEY` | 한글 제목·본문 |

`AppText`와 `AppTextInput`의 실제 굵기 매핑은 `apps/mobile/lib/typography.tsx`를 기준으로 합니다. 시스템 글자
크기를 키워도 본문을 고정 높이에 가두지 않으며, 핵심 상태와 행동은 글꼴·색상만으로 구분하지 않습니다.

`판매 시작`, `게시 완료`, `바로 공개됐어요`를 사용하지 않습니다.

## 맞춤 추천 문구 카탈로그

UI 제목은 항상 `맞춤 추천`, 항목 근거 label은 `추천 이유`를 사용합니다. `reasonCode`와 문구는 다음처럼
결정론적으로 대응합니다.

| reason code | 표시 문구 | 필요한 근거 |
| --- | --- | --- |
| `sport_match` | `선호 종목과 일치해요.` | profile sport와 listing sport 일치 |
| `skill_match` | `선택한 경험 수준 조건과 일치해요.` | 명시적 skill rule 충족 |
| `size_match` | `입력한 사이즈 범위에 들어와요.` | 단위가 정규화된 size 범위 일치 |
| `budget_match` | `설정한 최대 예산 안에 있어요.` | 같은 통화의 listing 가격이 예산 이하 |
| `condition_match` | `선택한 장비 상태와 일치해요.` | condition 선호 일치 |
| `ski_discipline_match` | `선호하는 스키 스타일과 일치해요.` | ski discipline 일치 |
| `binding_preference_match` | `바인딩 포함 선호와 일치해요.` | binding 포함 여부 일치 |
| `hockey_format_match` | `선택한 하키 형식과 일치해요.` | ice/street/roller format 일치 |
| `hockey_position_match` | `선택한 포지션 조건과 일치해요.` | position 또는 `any` rule 충족 |
| `handedness_match` | `선택한 스틱 방향과 일치해요.` | left/right 일치 |
| `pickup_area_match` | `선호 거래 지역에서 찾았어요.` | 사용자가 입력한 coarse 지역 일치 |

근거 입력이나 listing detail이 없으면 해당 이유를 만들지 않습니다. 이유 정렬 순서도 고정하고, 동일한 입력에는
동일한 code와 문구를 반환합니다. 이 규칙은 적합성 후보를 정리할 뿐 착용감, 안전성, 품질, 정품 여부나 구매를
보장하지 않습니다.
